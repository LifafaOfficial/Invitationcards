Status

Publish changes to all visitors

Saving here only changes this browser. GitHub Pages is static, so to update every visitor: (1) tap Download publish file, (2) in your GitHub repository upload lifafa-data.json next to index.html, replacing the old one, (3) wait about a minute and refresh the live site. It contains your published cards, brand, site text, contact and appearance settings. No password or token is included.

Photos or videos you uploaded through Cloudinary work for everyone. Files stored only in this browser (old local uploads) cannot be published.

Backup & restore

Files are checked before anything changes. A bad file is rejected and your data stays as it is.

Website health check

Checks your saved cards, settings and the loaded page. It never changes anything by itself; repairs show a preview and ask first.
